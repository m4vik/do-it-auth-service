# План и гейты Auth Service

Согласованный стек: C# / ASP.NET Core (.NET 10), PostgreSQL, Redis, Docker Compose.
Регистрация: выбор email или телефона. 2FA: одноразовые email/SMS-коды через лог-заглушку.
Frontend, TOTP, реальные провайдеры, роли и дополнительные сервисы не входят в объём.

| Гейт | Результат | Проверка |
|---|---|---|
| G0 | Окружение и контракт | .NET, Git, Docker, README с маршрутами |
| G1 | Контейнеры и миграции | Чистый запуск одной командой |
| G2 | Регистрация | Оба контакта, активность, уникальность, пароль-хеш |
| G3 | Вход и профиль | Вход без подтверждения; JWT и действующая сессия |
| G4 | Refresh/logout | Атомарная ротация, немедленный отзыв, гонки |
| G5 | Подтверждение | Email/SMS, TTL, лимиты, одноразовость |
| G6 | 2FA | Включение/выключение, отсутствие токенов до второго шага |
| G7 | Проверки | Unit и интеграционные тесты с PostgreSQL/Redis |
| G8 | Документация | README: запросы, Docker, архитектура и Git |
| G9 | Публикация | Публичный репозиторий и запуск из чистого клона |

Последовательность: окружение → каркас/БД → регистрация → сессии → коды/2FA → тесты → README → публикация.
Каждая законченная группа изменений сохраняется отдельным коммитом.
Точный API и действующие технические решения описаны в README.md.
Фактические результаты проверок фиксируются в VALIDATION.md; эта таблица сама по себе не означает закрытие гейтов.
